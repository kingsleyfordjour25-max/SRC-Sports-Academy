**SRC Sports Academy – Website Testing Report**



&#x20;**Introduction**

The SRC Sports Academy website was developed using HTML5, CSS and JavaScript, with jQuery for on-page searching. Testing was carried out to assess functionality, accessibility, responsiveness and compatibility.



&#x20;**Validation and Functionality Testing**

The W3C HTML and CSS Validation Services were used to check the website's code. Errors identified during validation were corrected, and the final HTML and CSS checks reported no errors.



Functional testing confirmed that the navigation links, footer links, search feature, CAPTCHA, visitor counter, registration form, booking form and newsletter form responded as expected. The website also displayed its images and background video correctly.



**Accessibility Testing**

Windows Narrator was used to assess screen-reader accessibility. It announced navigation links and interactive elements. Keyboard testing also confirmed that users could navigate using the Tab and Enter keys, with visible focus indicators. These features improve access for users with visual and physical disabilities.



**Cross-Browser Testing**

The website was tested using Google Chrome, Microsoft Edge and Mozilla Firefox. All three browsers displayed the pages correctly, and the navigation, images and responsive layouts behaved consistently. No significant differences were observed.



**Evaluation of Development Tools**

Notepad++ was used to write and edit the HTML, CSS and JavaScript files. It provided syntax highlighting and made code organisation easier. However, it does not provide a complete visual preview of the website.



Google Chrome Developer Tools provide browser-based inspection, debugging and responsive testing. They are useful for identifying layout and scripting problems, although they require some technical knowledge.



**Role of the W3C**

The World Wide Web Consortium (W3C) develops web standards and guidelines that promote accessibility, consistency and compatibility across browsers and devices. Its validation services help developers identify errors and produce more reliable websites.



**Three Important Web Services**

1.Web hosting:\*\* Stores website files on a server and makes the website accessible online.

2.Domain name registration and DNS:\*\* Provides a memorable website address and directs visitors to the correct server.

3.Email services:\*\* Enable communication between the academy, athletes, parents and visitors.



**Recommendations and Conclusion**

Future development should include a database and server-side processing to store registrations, manage bookings and handle newsletter subscriptions. A stronger server-side CAPTCHA, real social media accounts, online payments and an administration dashboard would also improve the website.



Overall, testing showed that the SRC Sports Academy website is functional, responsive and compatible with the three browsers tested.
